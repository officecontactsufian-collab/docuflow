# **App Name**: PDF Spark

## Core Features:

- PDF Merge: Allow users to combine multiple PDF documents into a single, unified file with a simple drag-and-drop interface.
- PDF Split: Enable users to extract selected pages from an existing PDF to create new, separate PDF documents.
- PDF Conversion: Convert PDF documents to common file formats (e.g., Word, Image) and vice-versa.
- File Upload & Download: Provide a secure mechanism for users to upload their PDF files and download the processed output files efficiently.
- AI Content Analysis Tool: Utilize an AI tool to offer features like summarizing PDF content or extracting key information points from documents.

## Style Guidelines:

- Primary color: A sophisticated and professional deep cyan-blue (#248BC7) to evoke trust and efficiency in document handling.
- Background color: A very light, subtly tinted off-white (#F2F7F8) provides a clean, unobtrusive canvas for PDF content and tools.
- Accent color: A vibrant yet authoritative blue-violet (#546CFF) used for calls to action, important highlights, and interactive elements to draw attention.
- Font: 'Inter' (sans-serif) for all text elements. Its modern, highly readable design ensures clarity and accessibility for instructional text and tool labels.
- Employ a consistent set of line-art icons that are simple, clear, and universally recognizable, directly communicating each PDF operation's function.
- A clean, functional, and user-centric layout featuring a prominent central drag-and-drop zone for file interactions and clearly defined tool cards.
- Subtle, non-distracting animations for transitions between states and feedback on file upload/processing progress, enhancing user experience without overwhelming it.
